# One challenge you faced in GitHub and how you solved it.

A challenge I faced in GitHub was when I was pushing the commit from the update-bio branch.
I originally had pressed 'Fetch origin' from the main branch, thus on Github.com I did not
see the pull request. I solved this by re-reading the directions, and noticing a part of 
the directions that wasn't fully clear to me--I interpreted it as we should push from main,
but on second read I saw how pushing from update-bio could have been implied. I then pushed
it from update-bio and was able to see the pull request.

# One way you see GitHub helping future team projects. 

One way I see GitHub helping future team projects is through management. With Github, we
will have a better understanding of who, did what, when they did it, etc.. I can see this
helping with quality control, too, through approval of pull requests before being pushed
into main. A question this brings up to me, though, is who would be the approver of these
requests? Thinking about a team project, would we need to establish a lead where their
role isn't development, but just approval and management? I don't think it's fair that
one person would have to develop and manage; this seems like an uneven distribution of 
work. Another idea is that approvals to main are pushed through a team approval, thus
you would need continual team meetings where this is the focus.
