# Step 1: Load the dataset  

First, load your dataset from the correct folder/file path on your computer.
Store that data set to a variable, such as 'data'.
Ensure the data set is loaded to the variable properly by viewing the variable.
Your variable should contain the appropriate data.

---

# Step 2: Clean the data (explain how)  

Complete the following steps to clean your data:
- Remove all rows that are fully NA/null.
- Remove all null/NA values; replace with appropriate values, such as 0.
Note: Appropriate values is subjective to data; use your judgement.
- Replace all outliers so the data isn't skewed.
- Normalize your data if needed.
- Fix any values as needed, such as key values, to ensure they are consistent. 

---

# Step 3: Calculate summary statistics  

The goal of this step is to get a good understanding of the distribution of the data.
We want to understand each variable/column, while also understanding their correlations.
Complete the following steps:
- Create a correlation calculations between all the variables.
- Calculate summary stats, such as mean, medium, minimum, maximum, Q1, Q3, etc.
- Add any other plots you deem necessary (scatter plots, bar charts, etc.)

---

# Step 4: Create a visualization  

Complete the following steps:
- Create frequency plots for each variable, so that we can better understand distributions.
- Create the correlation plots and implement them into this step; this allows us to see the 
correlations calculated from step 3.
- Create a box plot for each variable to better visualize it's distribution.

---

# Step 5: Interpret results  

Write a summary for each variable, explaining it's distribution with the calculated
summary stats, while using the visualizations to help support understanding for the
reader. 
Follow the same steps, now for the correlations between the variables.
